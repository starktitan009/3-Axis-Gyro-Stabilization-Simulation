# 🔒 Security Policy

## Supported Versions
This project does not currently maintain versioned releases.  
All security updates apply to the latest commit on the main branch.

---

## Reporting a Vulnerability
If you discover a security issue or vulnerability:
1. Please **do not** open a public issue.
2. Instead, contact the maintainer directly via email or GitHub private message.
3. Provide a clear description of the problem and steps to reproduce it.

We’ll review and address the report as soon as possible.

---

## General Guidelines
- Avoid committing sensitive data (API keys, passwords, tokens).
- Use secure communication protocols (HTTPS, encrypted serial links).
- Keep dependencies updated to prevent known vulnerabilities.

---

## Acknowledgment
We appreciate responsible disclosure and contributions that help keep this project secure.
